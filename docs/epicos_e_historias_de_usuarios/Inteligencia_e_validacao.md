# EP05 - Inteligência e Validação da Pré-Matrícula

## Descrição do Épico
Como aluno, quero filtrar disciplinas e alterar meus interesses durante o período de pré-matrícula para facilitar minhas escolhas e manter meus dados atualizados.

---

# Histórias de Usuário

## HU01 - Filtrar disciplinas

### Descrição
Como aluno, quero utilizar filtros por curso e turno para localizar disciplinas mais facilmente.

### Critérios de Aceitação
- O sistema deve permitir filtro por curso;
- O sistema deve permitir filtro por turno;
- O sistema deve atualizar os resultados automaticamente;
- O sistema deve informar quando não houver resultados.

---

## HU02 - Alterar disciplinas de interesse

### Descrição
Como aluno, quero alterar minhas disciplinas selecionadas para atualizar minha intenção de matrícula.

### Critérios de Aceitação
- O sistema deve permitir adicionar novas disciplinas;
- O sistema deve permitir remover disciplinas já selecionadas;
- O sistema deve salvar automaticamente as alterações;
- O sistema deve exibir confirmação visual após atualização.

---

## HU03 - Funcionalidade “Perdi o Interesse”

### Descrição
Como aluno, quero informar que perdi interesse em determinada disciplina para atualizar corretamente os dados de demanda.

### Critérios de Aceitação
- O sistema deve permitir remover a disciplina da lista;
- O sistema deve apresentar um campo de justificativa;
- O sistema deve registrar a alteração em tempo real;
- A disciplina removida não deve continuar contabilizada.

---

## HU04 - Controle do período de coleta

### Descrição
Como sistema, quero limitar o período de coleta da pré-matrícula para organizar o planejamento acadêmico.

### Critérios de Aceitação
- O sistema deve permitir alterações apenas durante 10 dias;
- O sistema deve informar o prazo restante ao usuário;
- O sistema deve bloquear alterações após o encerramento;
- O sistema deve exibir mensagem de coleta encerrada.

---

## HU05 - Atualização em tempo real

### Descrição
Como coordenador, quero visualizar atualizações em tempo real para acompanhar a demanda das disciplinas instantaneamente.

### Critérios de Aceitação
- O sistema deve atualizar os dados automaticamente;
- As alterações devem refletir imediatamente nos relatórios;
- O sistema deve evitar registros duplicados;
- O sistema deve manter a integridade dos dados.
