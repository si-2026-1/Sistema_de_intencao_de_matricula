# EP08 - Acompanhamento de Turmas e Demanda Acadêmica

## Descrição do Épico

Como professor, quero visualizar as turmas sob minha responsabilidade e acompanhar a demanda de interesse dos alunos para compreender o perfil das turmas e auxiliar no planejamento acadêmico.

---

## HU01 - Visualizar turmas vinculadas

### Descrição

Como professor, quero visualizar minhas turmas vinculadas para acompanhar suas informações acadêmicas.

### Critérios de Aceitação

* O sistema deve exibir as turmas vinculadas ao professor autenticado;
* O sistema deve apresentar nome e código da disciplina;
* O sistema deve exibir identificação da turma, horário e turno;
* O sistema deve informar quando não houver turmas vinculadas ao professor.

---

## HU02 - Visualizar demanda das turmas

### Descrição

Como professor, quero visualizar a quantidade de alunos interessados em minhas turmas para acompanhar a demanda acadêmica.

### Critérios de Aceitação

* O sistema deve exibir a quantidade de alunos interessados por turma;
* O sistema deve apresentar a disciplina e a turma correspondente;
* O sistema deve atualizar as informações após novas intenções de matrícula;
* O sistema deve informar quando não houver registros de interesse.

---

## HU03 - Visualizar indicadores acadêmicos da turma

### Descrição

Como professor, quero visualizar indicadores relacionados às turmas para compreender melhor o perfil da demanda dos alunos.

### Critérios de Aceitação

* O sistema deve apresentar indicadores relacionados ao progresso acadêmico dos alunos;
* O sistema deve diferenciar alunos conforme quantidade de reprovações;
* O sistema deve apresentar indicadores organizados por turma;
* O sistema deve exibir as informações de forma clara e organizada.
